## Запуск

Требуется Node.js 22+ (проверено на 24.18). Внешних зависимостей нет; шрифты и логотипы локальные.

```powershell
npm ci
npm run dev
```

Открыть http://127.0.0.1:5173. Сервер слушает только loopback. Другой порт: `$env:PORT='5174'; npm run dev`.

```powershell
npm run check
npm test
node --test tests/domain.test.js
npm run build
npm start
```

`build` собирает статические файлы в `dist/`; `start` обслуживает эту сборку. Не запускайте `dev` и `start` одновременно на одном порту. Для публикации можно использовать статический хостинг с содержимым `dist/`; навигация использует hash-маршруты.

## Разделы

- Главная: стиль мокапа, анимированный знак ФСП, переходы в оба кабинета.
- Вакансии: поиск, фильтры грейда/формата/нижней границы зарплаты/ФСП, сортировка, детали и сигнал интереса.
- Профиль: редактирование, доказательства навыков, настройки видимости и поиска, печать в PDF через браузер.
- Достижения: результат, личный вклад, источник; сценарий без истории ФСП.
- Задания: 3 учебных сценария, фиксированная рубрика, результат, объяснение и история попыток.
- Приглашения: принятие/отказ, фильтры статуса, вымышленный контакт после согласия.
- Мои отклики: сигналы интереса и их отзыв.
- Развитие: интересы отдельно от доказанных навыков, карта пробелов.
- Симуляция: подготовленный бриф и переход к учебной задаче.
- Работодатель: подбор кандидатов, основания, приглашение с зарплатной вилкой, отслеживание статуса.

Для сквозного сценария отправьте приглашение **кандидату #042**, примите его во вкладке «Приглашения» и вернитесь в кабинет работодателя. Выключение публикации/поиска в профиле убирает #042 из подборки.

## Границы прототипа

Все люди, компании, достижения, оценки и контакты синтетические. Проценты подбора иллюстративны. `localStorage` хранит изменения только на текущем устройстве; сброс — в профиле. Это не серверная авторизация и не защита данных разных пользователей. Используйте вымышленные сведения.

ФСП ID, email-регистрация, импорт резюме, реальные вакансии, LLM/голос, выполнение кода и серверная база не подключены. Печать PDF доступна через диалог браузера. Учебные вопросы не подтверждают профессиональный грейд; текстовое объяснение сохраняется без ИИ-оценки. Сигналы интереса и приглашения не отправляют внешние сообщения.

## Структура

```text
index.html             HTML-точка входа
src/app.js             экраны, маршрутизация, события и локальное состояние
src/domain.js          фильтрация, оценивание, статусы, валидация
src/data.js            синтетические данные и задания
src/styles.css         токены мокапа, адаптивная вёрстка, печать
public/assets/         логотипы из мокапа и локальные шрифты
scripts/               HTTP-сервер и статическая сборка
tests/                 бизнес-правила (node:test)
docs/                  исходная проектная документация
```

Стиль: JavaScript ES modules, 2 пробела, `.editorconfig`. Тесты проверяют фильтры, границы зарплаты, оценивание, ошибки ответов, переходы приглашений, подбор без ФСП и экранирование текста. Ручные сценарии: [docs/prototype.md](docs/prototype.md). Правила: [AGENTS.md](AGENTS.md).

Материалы организаторов сохранены для работы команды. Лицензия приложения пока не выбрана; включение брендовых материалов в репозиторий не означает передачу прав на них.
