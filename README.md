# ФСП на ЛЦТ 2026

Материалы спецтрека «Цифровая платформа-агрегатор ИТ-вакансий с верифицированным профилем достижений участника Федерации спортивного программирования».

Состояние на 5 октября 2026 года: собраны исходные материалы и проектные предложения. Реализация приложения ещё не начата; стек и название продукта не утверждены.

Начните с [навигатора документации](docs/README.md). Все материалы проекта находятся в `docs/`: требования, календарь, концепция, предложения по архитектуре и проверке качества, условия сдачи, оригиналы PDF/PPTX/RAR и распакованные ресурсы ФСП.

Команд сборки, запуска и тестирования приложения пока нет. При добавлении кода необходимо описать их здесь. Правила работы с репозиторием: [AGENTS.md](AGENTS.md).

Материалы организаторов сохранены для работы команды. Лицензия приложения пока не выбрана; включение брендовых материалов в репозиторий не означает передачу прав на них.
