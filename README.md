# ФСП на ЛЦТ 2026

Материалы спецтрека «Цифровая платформа-агрегатор ИТ-вакансий с верифицированным профилем достижений участника Федерации спортивного программирования».

На 9 октября 2026 года интерфейс заменён на предоставленный вариант **«ФСП Карьераитог / основной»**. Предыдущий тёмный прототип, его код, тесты и скриншоты удалены из текущей версии репозитория. Новая версия сохранена в `site/`; продуктовые документы и материалы команды остаются в `docs/`.

[Навигатор документации](docs/README.md), [спецификация нового дизайна](docs/design-spec.md), [границы и проверка мокапа](docs/prototype.md). Целевой стек рабочего приложения утверждён в [docs/stack.md](docs/stack.md); эта замена переносит предоставленный статический дизайн для просмотра, без миграции на серверный стек.

## Запуск

Требуется Node.js 22+ (проверено на Node.js 24). Внешних npm-зависимостей нет. Шрифты Golos Text и JetBrains Mono загружаются через Google Fonts, как в предоставленном варианте; при отсутствии интернета используются запасные шрифты.

```powershell
npm ci
npm run dev
```

Открыть http://127.0.0.1:5173. Сервер слушает только loopback. При занятом порте: `$env:PORT='5174'; npm run dev`.

```powershell
npm run check
npm test
node --test tests/site.test.js
npm run build
npm start
```

`check` проверяет внешний JS, встроенные скрипты каждой HTML-страницы и инструменты. `test` проверяет локальные ссылки, HTTP-страницы, типы ресурсов и закрытый доступ к служебным файлам. `build` создаёт чистую статическую сборку в игнорируемой `dist/`; `start` обслуживает её. Перед запуском production остановите dev или задайте другой порт.

## Страницы

- `/` — главная с графом соответствия, компаниями и модальным опросником.
- `/map.html` — кабинет: профиль, карта/список, поиск, сохранённые вакансии, навыки и окна разделов.
- `/interview.html` — сценарий ИИнтервью, текстовые ответы, имитация голосового ввода и демонстрационный результат.
- `/onboarding.html` — отдельная страница опросника.
- `/onboarding-split.html` — альтернативная компоновка опросника.

## Структура

```text
site/                   текущий сайт (статический экспорт)
  index.html            главная и модальный опрос
  map.html              кабинет и карта соответствия
  app.js, styles.css    код и стили карты
  interview.html        учебный сценарий интервью
  onboarding*.html      отдельные варианты опросника
  assets/               логотип и изображения экспорта
scripts/                локальный HTTP-сервер, сборка, проверка синтаксиса
  server.mjs
  build.mjs
  check.mjs
tests/site.test.js      проверки сайта и HTTP-сервера
docs/                   проектная документация и исходные материалы
  design-spec.md        спецификация предоставленного дизайна
  prototype.md          реализованные экраны, ограничения, проверки
  screenshots/          скриншоты текущего варианта
```

Статическую сборку `dist/` можно разместить на обычном хостинге. Все страницы используют относительные ссылки; серверные маршруты и API не нужны для просмотра.

## Публикация

Адрес сайта в ChatGPT Sites: [ФСП Карьера](https://fsp-career.fridonium.chatgpt.site/). Доступ открыт всем по ссылке, в том числе с телефона; локальный сервер для этого не требуется.

Связь с публикацией хранится в `.openai/hosting.json`. Для обновления нужно собрать `dist/` командой `npm run build` и опубликовать новую версию через Sites. В публичную сборку входят только файлы сайта, без документации и Git. Обычный `git push` в GitHub сам по себе сайт не обновляет.

## Границы

Это интерактивный дизайн-мокап с демонстрационными людьми, компаниями и цифрами. ФСП ID, распознавание PDF, проверка ИНН, голосовой ввод и оценка интервью имитируются. Функция интервьюера остаётся заглушкой; реальные LLM/API, авторизация и база не подключены. Результаты не подтверждают профессиональный грейд. Фильтры вне оговорённых в спецификации сценариев частично визуальные. Сохранение вакансий и настроек действует в рамках открытой страницы.

Материалы организаторов сохранены для работы команды. Лицензия приложения пока не выбрана; включение брендовых материалов в репозиторий не означает передачу прав на них. [AGENTS.md](AGENTS.md) задаёт правила разработки.
