# MESHWORK

Платформа подбора ИТ-специалистов с обратной механикой для спецтрека ФСП на ЛЦТ 2026. Кандидат получает
подтверждённую категорию (специализация × грейд) через ИИ-консультанта, адаптивный тест на грейд и три ступени
оценки; работодатель ищет по категоризированной базе и отправляет приглашение с зарплатой.

Стенд: https://fsp2.ru. Навигатор документации: [docs/README.md](docs/README.md). Правила разработки: [AGENTS.md](AGENTS.md).

## Состав репозитория

- `platform/` — продукт: Next.js 15, TypeScript, Prisma 6, PostgreSQL 16. Единственное, что сдаётся и деплоится.
  Запуск, переменные окружения и демо-режим без ключей — [platform/README.md](platform/README.md); карта модулей —
  [docs/modules.md](docs/modules.md).
- `fsp-sim/` — симулятор ФСП ID и API реестра достижений (Keycloak + Node, синтетические данные, отдельный сервер
  https://fsp-russia2.ru). Показывает схему будущей интеграции; интеграцией с ФСП не является —
  [fsp-sim/README.md](fsp-sim/README.md).
- `site/` — статический дизайн-референс (экспорт мокапа Карины). Код продукта в нём не пишется, экраны переносятся
  в `platform/`. Локальный просмотр: `npm ci && npm run dev` в корне, затем http://127.0.0.1:5173; `npm test`
  проверяет ссылки и сервер. Спецификация дизайна — [docs/design-spec.md](docs/design-spec.md).
- `docs/` — продуктовые решения, требования, исследования, материалы организаторов и результаты проверок.

## Деплой и сдача

Push в `main`, затрагивающий `platform/**`, разворачивает стенд через GitHub Actions (`deploy.yml`); проверки типов,
lint и тестов идут отдельным workflow `checks.yml` и деплой не блокируют. Подробности — [docs/deploy.md](docs/deploy.md),
сценарий показа — [docs/demo-script.md](docs/demo-script.md), документ сдачи —
[docs/submission/fsp-career.md](docs/submission/fsp-career.md).

## Границы честности

ФСП ID, реестр ФСП, проверка компаний и демо-резюме — симуляции; параметры заданий теста — экспертные оценки, не
калиброванные на людях. Цифры с командами, которые их получили, — [docs/validation-results.md](docs/validation-results.md).
