# Документация MESHWORK (спецтрек ФСП, ЛЦТ 2026)

Материалы для разработки и сдачи решения на ЛЦТ 2026. Актуальность: **11 октября 2026 года** (МСК).

Кандидат подтверждает квалификацию тестом на грейд, затем созвоном с ИИ, проектом из ленты обезличенных заданий и защитой проекта (три ступени оценки, [ADR 0003](decisions/0003-three-stage-assessment.md)); работодатель получает объяснимую подборку и направляет приглашение с зарплатой. Подбор даёт 35% оценки, тестирование и валидация — 25%.

**Ближайший срок:** сдача решения — 11 октября до 23:59 МСК; документ сдачи — [submission/fsp-career.md](submission/fsp-career.md). Встреча экспертов 6 октября и письменные ответы разобраны ниже. [Объявления организаторов](organizer-updates.md).

**Обновление 11 октября:** [широкий аудит соответствия](compliance-audit-2026-10-11.md) проверяет свежий код, тесты, ограничения качества и доступ жюри. Для сдачи сегодня нужны репозиторий, презентация, демо (или запись при его отсутствии) и документация в PDF; загрузка — в личный кабинет. [Новые ответы организаторов через Telegram MCP](organizer-updates.md#новые-разъяснения-8–11-октября). Старые трассировка, метрики и сценарии имеют дату своего снимка; не считать их описанием текущей политики теста без сверки с аудитом.

## Статус и приоритет источников

Требования ТЗ и инструкции организаторов отделены от проектных предложений. При расхождении раннего описания кейса и подробного ТЗ используем ТЗ; уточнения организаторов приведены со ссылками и датами. Расхождения новых ответов по LLM и принудительному понижению грейда отмечены в [списке вопросов](questions-for-organizers.md), без автоматической отмены требований ТЗ.

Продукт — `platform/` на принятом стеке ([stack.md](stack.md)): путь кандидата с консультантом, адаптивный тест на грейд (четыре направления, 18 подкатегорий, три грейда), кабинет работодателя с подбором и приглашениями и три ступени оценки: созвон, проект с автопроверкой в песочнице, защита проекта. `site/` — статический дизайн-референс ([корневой README](../README.md), [спецификация дизайна](design-spec.md)). Что есть в коде — [platform.md](platform.md) и [modules.md](modules.md); цифры валидации — [результаты проверки](validation-results.md) и [валидация ступеней](validation-stages.md); показ — [сценарий для жюри](demo-script.md). Ранние предложения по архитектуре, концепции и плану проверки удалены 11 октября: по расхождениям верен код и документы выше.
