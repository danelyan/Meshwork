# Документация MESHWORK (спецтрек ФСП, ЛЦТ 2026)

Актуальность: **11 октября 2026 года** (МСК). Продукт находится в `platform/`.
Кандидат проходит знакомство с ИИ-консультантом, тест на грейд, созвон, проект и защиту.
Работодатель получает объяснимую подборку и отправляет приглашение с зарплатой.
