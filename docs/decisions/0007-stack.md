# 0007. Стек: единый Next.js и TypeScript

Статус: **принято владельцем 9 октября 2026 года.** Таблица версий и слоёв – [stack.md](../stack.md); здесь только решение и причина.

Требования: R-T-*, R-N-*. Критерий оценки 4 (техника), косвенно 1–2.

## Вопрос

Срок сдачи – 11 октября 2026, 23:59 МСК; серверный стек команды утверждён не был (статический прототип без API и базы). Какой стек брать, чтобы за оставшееся время получить агента с инструментами, чтение ссылок и файлов, почту и PDF.

## Варианты

1. **Единый Next.js + TypeScript** – готовые части (цикл агента с инструментами, чтение ссылок с защитой от SSRF, разбор PDF/DOCX, подтверждение почты) переносятся без миграции версий; один язык и репозиторий. Минус: дизайн прототипа переносится в React.
2. Fastify + TypeScript на сервере, фронт прототипа на чистом JS – фронт не трогаем, но два стека и ручная стыковка.
3. Python + FastAPI – всё пишется с нуля.

## Решение

Вариант 1, серверную часть и агента ведёт Иван Ветров. Слои: Node.js и TypeScript, Next.js 15 (App Router), React 19, Zod, Prisma и PostgreSQL 16, `openai` SDK с OpenAI-совместимым адаптером (провайдер в конфигурации), Docker Compose, Mailpit.

**Критерий «российской» модели (владелец):** данные не покидают РФ – этого достаточно для 152-ФЗ. Допустимы Alice/YandexGPT, GigaChat и открытые модели, размещённые в Yandex Cloud или на своём железе в РФ. Основание для открытых моделей – письменный ответ организаторов (облачные LLM допустимы, открытые предпочтительнее, риски 152-ФЗ на команде). Не допускаются API разработчика модели и внешние провайдеры каталога Cloud.ru. Провайдер сменный: выбор модели стенда – по замеру, результаты в [validation-results.md](../validation-results.md).

## Последствия

- Дизайн прототипа переносится в React-компоненты; `site/` остаётся дизайн-референсом, `platform/` – единственный продукт ([README.md](../../README.md)).
- Next.js тяжелее Fastify в сборке – на слабых машинах сборки последовательно.
- Лицензия решения – MIT (`LICENSE`).
- Локальная языковая модель не используется (нет GPU).
