# 0007. Стек: единый Next.js и TypeScript

Статус: **принято владельцем 9 октября 2026 года.** Таблица версий и слоёв – [stack.md](../stack.md); здесь только решение и причина.

Требования: R-T-*, R-N-*. Критерий оценки 4 (техника), косвенно 1–2.

## Решение

Серверная часть и агент используют единый Next.js и TypeScript. Слои: Node.js и TypeScript, Next.js 15 (App Router), React 19, Zod, Prisma и PostgreSQL 16, `openai` SDK с OpenAI-совместимым адаптером (провайдер в конфигурации), Docker Compose, Mailpit.

**Критерий «российской» модели (владелец):** данные не покидают РФ – этого достаточно для 152-ФЗ. Допустимы Alice/YandexGPT, GigaChat и открытые модели, размещённые в Yandex Cloud или на своём железе в РФ. Основание для открытых моделей – письменный ответ организаторов (облачные LLM допустимы, открытые предпочтительнее, риски 152-ФЗ на команде). Не допускаются API разработчика модели и внешние провайдеры каталога Cloud.ru. Провайдер сменный: выбор модели стенда – по замеру, результаты в [validation-results.md](../validation-results.md).

## Последствия

- `platform/` содержит интерфейс, API и серверные модули продукта.
- Next.js тяжелее Fastify в сборке – на слабых машинах сборки последовательно.
- Лицензия решения – MIT (`LICENSE`).
- Локальная языковая модель не используется (нет GPU).
