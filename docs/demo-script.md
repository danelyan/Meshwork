# Сценарий показа жюри

Длительность **3–5 минут**, три демо-кандидата. Что показываем: резюме превращается в утверждения с цитатами, ничего не попадает в профиль без клика кандидата, уровень доказанности ставит код, скрытая инъекция найдена и проигнорирована, отсутствие истории ФСП не штрафуется. Описание устройства — в [платформе](platform.md), оговорки по цифрам — в [результатах проверки](validation-results.md).

## Подготовка (за час до показа)

```bash
cd platform
# .env: LLM_PROVIDER=stub  LLM_STUB_DEMO=true  COLLECTOR_FIXTURES=true  DEMO_LOGIN=true
npx prisma migrate deploy && npm run db:seed      # 3 демо-кандидата, каталог, вакансии, задания
node eval/scripts/make-pdfs.mjs --out /tmp/fsp-demo   # demo-1.pdf, demo-2.pdf, demo-3.pdf
npm run dev                                       # или docker compose up --build
curl -s localhost:3000/api/health                 # {"ok":true,"db":"up","llm":"stub"}
```

- Режим без ключей: извлекатель работает по словарю каталога, консультант отвечает по ключевым словам. Для показа этого достаточно — шаги, карточки, цитаты, уровни и защита от инъекций выполняются настоящим кодом. Если появятся ключи языковой модели, достаточно сменить `LLM_PROVIDER`; сценарий тот же.
- Прогнать весь путь накануне и на стенде заново: число карточек ниже ориентировочное (минимумы из разметки демо-набора: 8, 4 и 3).
- Перед каждым показом пересоздать данные демо-кандидатов (`npm run db:seed` не стирает прежние утверждения; для чистого прогона — новая БД или новый кандидат). Иначе повторное резюме вернёт «уже загружено», а отклонённые карточки не предлагаются заново.
- Запасной вариант на случай сбоя стенда — записанное видео этого же сценария ([сдача](delivery.md) допускает видео вместо живого стенда).

## Что может пойти не так

| Проблема | Причина | Что делать |
| --- | --- | --- |
| Карточек нет, шаг «нашёл 0» | Стенд не в режиме словарной заглушки (`LLM_STUB_DEMO=false`) или файл не PDF/DOCX | Проверить `.env`, перезапустить; шаг «читаю…» должен показать число строк |
| «Файл уже загружен» (`deduplicated`) | Тот же файл у того же кандидата | Использовать нового демо-кандидата или чистую БД |
| На шаге 6 приходит «Заглушка LLM: …» вместо рекомендаций | Сообщение набрано словами, а не маркером | Отправить маркер `[[tool:…]]` как есть; заглушка понимает только его |
| Ответ 409 `busy` | Предыдущий ход ещё идёт | Подождать конца потока (`done`) и отправить снова |
| «Доказать защитой» отвечает ошибкой 409 | Утверждение ещё не подтверждено или уже «платформа» | Сначала нажать «Да» на карточке |
| Защита завершается «не пройдено» | В режиме без ключей оценщик — заглушка, она всегда отказывает; вопросы шаблонные | Заранее сказать: «вердикт без модели всегда отрицательный, с моделью уровень поднимется». Показать сами вопросы и то, что уровень без вердикта не меняется |
| Ошибка 429 в защите | Уже две попытки на утверждение за 30 дней | Взять другое утверждение или нового кандидата |
| «Упрощённый режим» в чате | Провайдер недоступен или исчерпан дневной бюджет токенов | Это план В: словарное извлечение и шаблонные ответы работают; сказать об этом как о свойстве |
| В резюме другое имя, чем у демо-аккаунта | Имя в PDF — персонаж набора, аккаунт — отдельный демо-вход | Не комментировать; данные и так вымышлены |
| На странице профиля нет вакансий | Список вакансий показывается только в чате (шаг 6), профиль выводит пробелы и задания | Показать вакансии в чате |
| Нет сети или GitHub недоступен | При `COLLECTOR_FIXTURES=true` сеть для профилей не нужна: используются фикстуры | Убедиться, что флаг включён; ссылки только `demo-ryabinin`, `demo-vlasova`, `demo-lisitsyn` |
| Playwright или браузер на стенде другой версии | Штатный Chromium проекта не установлен на машине показа | К показу не относится; запускать вручную в обычном браузере |

## Чего не обещать

Не говорить, что качество извлечения проверено на модели: цифры получены на словаре и оптимистичны. Не говорить про регистрацию, тест, приглашения и кабинет работодателя как о готовом: в этом контуре их нет ([что на заглушках](platform.md)). Категории в профиле на демо не будет — её даёт тест.
