# ФСП Карьера - спецификация дизайна (вариант «основной»)

Папка самодостаточна: открыть `index.html` в браузере. Внешние зависимости - только Google Fonts.

## 1. Файлы

| Файл | Что это |
|---|---|
| `index.html` | Главная (лендинг) + опросник во всплывающем окне. CSS и JS внутри файла |
| `map.html` + `styles.css` + `app.js` | Личный кабинет после входа: боковая панель профиля + карта соответствия |
| `interview.html` | ИИнтервью (интервью с ИИ после теста на грейд). CSS и JS внутри |
| `onboarding.html` | Тот же опросник отдельной страницей (запасной вариант) |
| `onboarding-split.html` | Тест: опросник на левой половине экрана |
| `assets/fsp-mark.svg` | Звезда ФСП (всегда монохром: `filter:grayscale(1) brightness(0)`, на тёмном + `invert(1)`) |
| `assets/person-0.webp` | Фото пользователя «Вы». `person-1..11` - не используются (у других людей силуэты) |

Важно про `styles.css`: он собран слоями - базовые стили исходного сайта, затем блоки-переопределения (`/* ===== 15a ...`, `15b`, `15c`, `ТЕСТ квадраты`, `боковая панель профиля`). Побеждает последний блок. При переносе в продакшен - свести в один набор токенов по этому документу.

## 3. Шрифты

- **Golos Text** 400/500/600/700/800 - весь интерфейс, заголовки, кнопки.
- **JetBrains Mono** 400/500/600/700 - только технические подписи: кикеры, счётчики, проценты, метки, имена кандидатов на графе.

```
https://fonts.googleapis.com/css2?family=Golos+Text:wght@400;500;600;700;800&family=JetBrains+Mono:wght@400;500;600;700&display=swap
```

## 4. Форма и сетка

- **Скругления: 0 везде** (квадратная эстетика). Исключение - голова силуэта (круг внутри квадрата).
- Отступы страницы: 56px (≤1150px - 28px, ≤640px - 16px).
- Шапка: высота 96px (мобильная 72px), sticky, стекло, нижняя граница.
- Тени: плитки компаний `0 8px 24px rgba(17,17,17,.08)`; фото «Вы» `0 14px 34px rgba(17,17,17,.12)`; модалка `0 40px 100px rgba(17,17,17,.18)`.
- Разделители секций: сверху `1.5px solid #111`, внутри колонок `1px solid var(--line)`.
- Easing: `cubic-bezier(.65,0,.25,1)`.

## 5. Компоненты

**Шапка:** звезда ФСП 34px + «/карьера» (muted 15px) · навигация (15px muted, hover - фон `rgba(17,17,17,.05)`) · метка выпуска (Mono 12px uppercase, рамка 1px #111, «№ 01 · осень 2026») · «Войти через ФСП ID» (чёрная, 48px, hover - синяя).

**Кнопки:** primary - синяя, hover - чёрная. Ghost - белая `.6`, рамка `rgba(17,17,17,.18)`, hover - рамка #111. Стрелка «→» обычным весом.

**Варианты в опросе:** высота 64px, фон `rgba(255,255,255,.8)`, рамка `.10`. Слева квадрат-номер 30px (Mono 12px), справа квадрат-отметка 20px. Выбрано: рамка `1.5px #402FFF`, номер и отметка залиты синим, в отметке белый квадрат 8px (одиночный выбор) или белая галочка (множественный).

**Чипы:** 40px, рамка `.12`; выбранный - чёрный с белым текстом.

**Ползунок:** большое значение Golos 46px 700 + единица Mono 14px; `accent-color:#402FFF`.

**Загрузка PDF:** пунктирная рамка `1.5px dashed rgba(17,17,17,.25)`, иконка-лист с загнутым углом «PDF»; hover/перетаскивание - синяя рамка; после загрузки - сплошная синяя рамка, полоса прогресса, затем теги распознанного (Mono 12px на `#F1F1F3`).

**Кнопка ФСП ID:** чёрная 58px с белой звездой; после входа - белая с синей рамкой «Александр Ким · призёр ФСП 2025 · вошли ✓».

**Переключатель:** 40×22, квадратный бегунок 16px; включён - синий.

**Строка поиска (карта):** одна белая панель 64px: лупа · поле · «Очистить» (появляется при вводе) · иконка фильтра (3 полоски) со счётчиком · синяя «Найти». По клику на иконку под строкой выезжает ряд кнопок-дропдаунов 40px (Специализация, Грейд, Стек, Зарплата, Формат, Занятость, Компания, Соответствие); у каждой своё всплывающее окно; активная - чёрная со счётчиком; «Сбросить всё». Всё стекло, без жирных обводок.

## 6. Граф (главная и карта)

| Узел | Вид |
|---|---|
| Компания | белый квадрат 58px (карта 76px), рамка `.12`, буква Golos 800 36px; подпись снизу Mono 11px uppercase на подложке `rgba(241,241,243,.85)`. Выбранная на карте - чёрная |
| Вы | фото 96px ч/б (`grayscale(1)`), рамка `1.5px #111`, белый внутренний отступ 4px, подпись «Вы» Golos 700 |
| Кандидат | квадрат 34-44px `#E6E6EA` с белой рамкой 2px; силуэт `#111` - SVG `viewBox 0 0 44 44`: круг `cx22 cy16 r8` + плечи `M6 44c1.5-10 8-15 16-15s14.5 5 16 15z`. Связан/наведение - синий фон, белый силуэт |

Связи: ваши - синие 1.6-1.8px с подписью % (чёрная плашка); остальные - `#111` с прозрачностью .14-.22, 1-1.1px. По каждой синей связи бежит синий квадратик 6px (цикл ~4.5 с).

Движение: каждый узел покачивается ±7px (синус, свой сдвиг фазы), линии пересчитываются каждый кадр. На главной граф уходит за правый край экрана: основной кластер в 10-80% ширины, дополнительные узлы на 90-130% обрезаются краем.

## 7. Фон: живая сетка (canvas, все страницы)

- Сетка квадратов шаг 46px, на всё окно (`position:fixed; z-index:-1`).
- Узлы - квадраты 2px `rgba(17,17,17,.14+)`; линии сетки 1px, прозрачность от .045 до .245 (6 уровней).
- Мышь: радиус 230px, узлы отталкиваются до 30px (`(1-d/R)²`), рядом с курсором становятся синими 3px.
- Карточки «Сейчас нанимают» тоже раздвигают сетку: радиус 0.8 ширины карточки, сила 9px, свечение 0.38 от мышиного.
- Покой: волна ±2.2px. Сглаживание: `p += (target-p)*0.18`, мышь `*0.12`.
- `prefers-reduced-motion` - без волны и анимаций.

## 8. Главная (`index.html`)

1. **Hero** (на весь экран): кикер «ИТ-подбор с обратной механикой» · H1 «Работодатели сами придут к тебе.» (точка синяя) · слоган · кнопка «Приступим →» (84px, синяя, hover - чёрная и стрелка отъезжает) · под ней 3 метки Mono с синими квадратами «≈ 2 минуты / можно загрузить резюме PDF / или войти через ФСП ID» · справа плавающий граф без рамки.
2. **«Сейчас нанимают»**: бесконечная лента карточек компаний, плывёт вправо (240 с на круг), каждая покачивается (9.5-14 с, разные фазы), края ленты растворяются маской; пауза при наведении. Карточка 360×250, стекло: логотип 64px, название 24px, стек/описание Mono 13px, низ «N вакансий · до XXXk» (вилка синим). Клик - открывает опросник.
3. **«Почему это работает»**: 4 колонки (01 Тест вместо резюме · 02 Вилка всегда · 03 Контакты после «да» · 04 ФСП в зачёт), номер Mono синий. Ниже стеклянная полоса цифр: 6 940 / 186 / ≈ 68% / 3 в неделю.
4. **Финальная плашка** чёрная: «Пусть вас найдут.» + белая кнопка «Приступим».
5. Футер: стекло, Mono 11px uppercase.

## 9. Опросник (модалка на главной)

Окно `min(640px,94vw)`, квадратное, стекло `.86`, фон за ним размыт. Сверху сегментный прогресс (сделано - чёрный, текущий - синий), счётчик «3 / 8», крестик. Снизу «←» и синяя «Продолжить». Клавиши: 1-9 выбор, Enter дальше, Esc закрыть. Одиночный выбор сам переходит дальше через 260 мс.

**Кандидат:** Кто вы → Быстрый старт (PDF / ФСП ID / вручную) → Направление (8, в 2 колонки) → Грейд (Junior/Middle/Senior/Lead, подсказка «менять раз в 3 месяца») → Стек (чипы, можно пропустить) → Формат (несколько) → Ожидания (ползунок 60-600 тыс) → ФСП (пропускается, если вошли через ФСП ID) → Сводка → «Пройти тест на грейд» → карта.

PDF заполняет направление, грейд, стек, формат - у этих шагов метка «из резюме» (синяя плашка у eyebrow).

**Работодатель:** Кто вы → ИНН (поле Mono 20px + «Найти», затем карточка «проверено ✓», можно пропустить) → Направление → Грейды (несколько) → Сколько людей → Верхняя граница вилки (80-800 тыс) → Сводка → «Открыть рейтинг кандидатов».

## 10. Кабинет (`map.html`)

- Слева боковая панель 260px (стекло, sticky): фото 48px + имя + роль Mono; «Профиль заполнен 60%» с синей полосой и «+ Загрузить резюме PDF»; меню (Моя карта - активный чёрный, Профиль, Навыки и грейд «Middle», Приглашения «3» синяя плашка, Сохранённое, Тест на грейд «82», ИИнтервью «новое», Настройки); внизу «Профиль виден компаниям» (переключатель) и «Выйти». Пункты открывают окна с данными. Одинакова для кандидата и работодателя.
- Справа: заголовок, слоган, строка поиска с фильтрами, карта соответствия (граф в стеклянной панели), справа профиль выбранной вакансии (процент Golos 96px 700, требования, рейтинг, кнопки).
- ≤1050px панель становится горизонтальной строкой меню.

## 11. ИИнтервью (`interview.html`)

- Шапка 80px: звезда · «ИИнтервью» (второе «И» синее) + «Backend · Middle · после теста 82/100» · таймер Mono с мигающим синим квадратом · «Завершить».
- Стартовая карточка: «Следующий шаг - ИИнтервью», 4 правила (≈ 25 мин / 5 блоков / текст или голос / без камеры), синяя «Начать ИИнтервью».
- Чат (до 880px): ИИ - чёрный квадрат «ИИ» и белый пузырь с меткой этапа (Mono синий); ответы - синий пузырь справа с фото. Индикатор «печатает» - 3 мигающих квадрата.
- Быстрые кнопки: Повторить / Уточнить / Пропустить. Ввод: поле + микрофон (при записи - анимированная волна) + «Ответить».
- Справа 340px: этапы (Знакомство, Разбор теста, Системный дизайн, Работа в команде, Итоги) и 4 критерия с полосками; заметка о приватности.
- Финал: карточка с синей рамкой «Middle подтверждён · итог 84/100», сильные стороны, зона роста, рейтинг, кнопки на карту.
- Подключение LLM: функция `interviewer(answer)` в скрипте - сейчас заглушка, вопросы в массиве `SCRIPT`.
