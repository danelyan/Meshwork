## Приоритет источников

Раннее описание S2 обещает API или мок ФСП; подробное ТЗ S1 прямо исключает выдачу API, структуры и данных. Для реализации используем S1. Сроки и требования к презентации уточнены в S5.

При обновлении ТЗ или появлении ответа организатора добавлять дату и ссылку, затем обновлять затронутые требования. Пароли доступа к материалам в репозитории не хранить.
