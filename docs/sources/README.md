## Приоритет источников

Раннее описание S2 обещает API или мок ФСП; подробное ТЗ S1 прямо исключает выдачу API, структуры и данных. Для реализации используем S1. Сроки и требования к презентации уточнены в S5 и S9; S9 требует итоговую документацию в PDF и презентацию уже 11 октября.

При обновлении ТЗ или появлении ответа организатора добавлять дату и ссылку, затем обновлять затронутые требования. Пароли доступа к материалам в репозитории не хранить.

В S7 и S8 есть расхождение о допустимости зарубежных LLM; в S8 предложено автоматическое понижение грейда, которое S1 запрещает. Эти вопросы сохраняются как требующие уточнения, а не как уже изменённые требования. Дата получения XLSX не устанавливает порядок авторства ответов.
