# Источники логотипов компаний

Дата получения: 11.10.2026, Москва.

Это примеры известных технологических работодателей. Они **не заявлены партнёрами, клиентами или участниками ФСП Карьеры**. Подпись на сайте должна сохранять это различие; ссылка ведёт на публичную карьерную страницу компании. Подборка не является агрегатором вакансий: объявления, зарплаты и количество открытых позиций не загружались и не сохранялись.

Файлы сохранены в исходном виде, без перерисовки, перекрашивания, обрезки или конвертации. PNG/JPEG взяты по ссылкам логотипов из публичных страниц работодателей hh.ru; три SVG взяты с официальных сайтов компаний. API hh.ru/employers вернул HTTP 403, поэтому поле API `logo_urls` не использовано. Файлы HH CDN включают исходные поля/подложки; сохранять пропорции через `object-fit: contain`. Монохромный режим интерфейса и возврат исходного цвета при наведении задаются CSS, исходники остаются цветными.

## Проверка

Все активные файлы получены успешными HTTP-запросами. Растровые логотипы визуально проверены; три SVG разобраны как XML, имеют собственные размеры и исходные фирменные цвета. SVG не содержат скриптов, внешних ссылок или foreignObject. Карьерные страницы Яндекса, Т-Банка, Авито, Сбера, VK и МТС ответили HTTP 200. Сайты job.ozon.ru и alfabank.ru/career вернули HTTP 403 автоматическому клиенту; для Ozon и Альфа-Банка в реестре используются доступные публичные профили hh.ru. Актуальная официальная карьерная страница Альфа-Банка, найденная поиском: https://job.alfabank.ru/. HTTP 403 не выдается за проверку доступности сайта для обычного пользователя.

Названия и логотипы принадлежат соответствующим правообладателям; получение файла из открытого источника не означает передачу исключительных прав или подтверждение партнёрства. Официальные правила Яндекса: <https://yandex.ru/company/rules/logotype/>. Не использовать формулировки «нам доверяют», «наши партнёры», «нанимают через нас» без фактического подтверждения.
