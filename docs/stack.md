# Стек

Статус: **принят 9 октября 2026 года** (Иван Ветров ведёт серверную часть и
агента). Заменяет раздел «Вариант стека» в [архитектуре](architecture.md).
Текущий [мокап](prototype.md) — импорт предоставленных HTML/CSS/JS-страниц в
`site/` без npm-зависимостей. Карьерный консультант и серверная часть реализованы
на этом стеке в каталоге `platform/` ([что реализовано](platform.md)); версии ниже
взяты из `platform/package.json` и установленных пакетов на 9 октября.

## Выбор

| Слой | Решение | Почему |
| --- | --- | --- |
| Рантайм | Node.js 24 (образ Docker; `engines` допускает ≥ 22), TypeScript 5.9 | Один язык на сервере и в интерфейсе |
| Веб и API | Next.js 15.5 (App Router, route handlers), React 19 | Кабинеты и API в одном приложении; `output: 'standalone'` — штатная сборка для Docker |
| Валидация | Zod 4.6 | Одни схемы для API, форм и ответов LLM |
| Данные | Prisma 6.19, PostgreSQL 16; pgvector — только если понадобится векторный поиск | Миграции и типизированные запросы; модель данных — в [архитектуре](architecture.md) |
| LLM | `openai` SDK 6.49 через OpenAI-совместимый адаптер; провайдер в конфигурации | Провайдер меняется без правки кода |
| Файлы кандидата | unpdf 1.8 (PDF), mammoth 1.12 (DOCX) | Чтение резюме и документов в чате консультанта |
| HTML в текст | `node-html-parser` 7 | Страницы и README по ссылке превращаются в текст; парсер даёт дерево, по которому находятся скрытые элементы (`display:none`, нулевая прозрачность, мелкий кегль, вынос за экран) — их текст получает пометку и не может стать цитатой. Регулярными выражениями это надёжно не решается |
| Сетевой слой сборщика | `undici` 7 | Встроенный `fetch` не даёт указать, к какому IP подключаться. `undici` даёт свой `connect.lookup`: соединение идёт строго на адрес, прошедший проверку, поэтому подмена DNS между проверкой и запросом (DNS-rebinding) не сработает. Редиректы обрабатываются вручную, каждый хост проверяется заново |
| PDF профиля | Печать из браузера; серверный PDF (Puppeteer) — при наличии времени | Без Chromium в контейнере по умолчанию |
| Почта | Mailpit с веб-ящиком на демо | Письма подтверждения видны жюри без внешней доставки. Сервис поднят в Compose, но письма пока не отправляются: регистрации по email в платформе нет |
| Тесты | Vitest 4 + Testing Library (модули, компоненты, API), Playwright 1.64 (сквозные сценарии) | Связка из официальной документации Next.js; async Server Components проверяются только сквозными тестами |
| Запуск | Docker Compose: `app`, `db`, `mailpit`; обратный прокси с HTTPS — на стенде | Один `docker compose up` |

Готовые части (цикл агента с инструментами, чтение ссылок с защитой от
внутренних адресов, разбор PDF/DOCX, подтверждение email, генерация PDF)

## Авторизация

Вход в один клик через Яндекс ID: свой OAuth 2.0 authorization code flow с
`state` и PKCE (S256) поверх подписанной HMAC-куки сессии `cid`, без
Auth.js и без новых зависимостей. Аккаунт `User` с ролью `pending → candidate |
employer` (роль выбирается в онбординге), внешний вход — `AuthAccount
(provider, providerAccountId)`, токены Яндекса не хранятся. На `/auth` только Яндекс ID. Демо-аккаунты (готовые
кандидаты и работодатель) — отдельная страница `/demo` и `/api/demo/login`,
они доступны только при `DEMO_LOGIN=true` (на проде выключить, иначе 404).
Без `YANDEX_CLIENT_ID`/`YANDEX_CLIENT_SECRET` кнопка Яндекса неактивна.
Кука с верной подписью, но без аккаунта/кандидата в БД (пересид, очистка в другом окне) считается гостевой: страница → `/api/auth/stale` стирает куку и ведёт на `/auth`, API → 401 `session_stale`, шапка — «Войти».
Решение и альтернативы — [ADR 0001](decisions/0001-auth-yandex-id.md).

## Языковая модель

Требование: **персональные данные не покидают РФ** (152-ФЗ). Подходят
YandexGPT/Alice AI (Yandex AI Studio), GigaChat, а также открытые модели,
размещённые в РФ (например, в Yandex Cloud). Зарубежные API для данных
кандидатов не используем. Конкретная модель выбирается по качеству и
поддержке вызова инструментов; первая проверка — пробный запрос с одним
инструментом. Если вызов инструментов не работает, модель отвечает строгим
JSON по схеме Zod, а шаги выполняет код.
