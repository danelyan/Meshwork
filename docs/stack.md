Статус: **принят 9 октября 2026 года** (Иван Ветров ведёт серверную часть и
агента). Заменяет раздел «Вариант стека» в [архитектуре](architecture.md).
Текущий [мокап](prototype.md) — импорт предоставленных HTML/CSS/JS-страниц в
`site/` без npm-зависимостей. Карьерный консультант и серверная часть реализованы
на этом стеке в каталоге `platform/` ([что реализовано](platform.md)); версии ниже
взяты из `platform/package.json` и установленных пакетов на 9 октября.

## Авторизация

Вход в один клик через Яндекс ID: свой OAuth 2.0 authorization code flow с
`state` и PKCE (S256) поверх подписанной HMAC-куки сессии `cid`, без
Auth.js и без новых зависимостей. Аккаунт `User` с ролью `pending → candidate |
employer` (роль выбирается в онбординге), внешний вход — `AuthAccount
(provider, providerAccountId)`, токены Яндекса не хранятся. На `/auth` доступны вход и регистрация по email с кодом подтверждения, а также Яндекс ID при настройке OAuth. Демо-аккаунты (готовые
кандидаты и работодатель) — отдельная страница `/demo` и `/api/demo/login`,
они доступны только при `DEMO_LOGIN=true` (на проде выключить, иначе 404).
Без `YANDEX_CLIENT_ID`/`YANDEX_CLIENT_SECRET` кнопка Яндекса неактивна.
Кука с верной подписью, но без аккаунта/кандидата в БД (пересид, очистка в другом окне) считается гостевой: страница → `/api/auth/stale` стирает куку и ведёт на `/auth`, API → 401 `session_stale`, шапка — «Войти».
Решение и альтернативы — [ADR 0001](decisions/0001-auth-yandex-id.md).

## Языковая модель

Требование: **персональные данные не покидают РФ** (152-ФЗ). Подходят
YandexGPT/Alice AI (Yandex AI Studio), GigaChat, а также открытые модели,
размещённые в РФ (например, в Yandex Cloud). Зарубежные API для данных
кандидатов не используем. Конкретная модель выбирается по качеству и
поддержке вызова инструментов; первая проверка — пробный запрос с одним
инструментом. Если вызов инструментов не работает, модель отвечает строгим
JSON по схеме Zod, а шаги выполняет код.

**Стенд (9 октября): DeepSeek V4 Flash в Yandex Cloud** через OpenAI-совместимый
Chat Completions: `LLM_PROVIDER=openai-chat`,
`OPENAI_CHAT_BASE_URL=https://ai.api.cloud.yandex.net/v1`,
`OPENAI_CHAT_MODEL=deepseek-v4-flash`, ключ — API-ключ сервисного аккаунта.
Ответы стримятся. Alice AI LLM отклонена: в живом агенте не вызывает
инструменты и чаще выполняет инъекции. Цифры — [validation-results](validation-results.md#языковая-модель-yandex-cloud-9-октября).

Ресурсы Yandex Cloud: каталог `fsp-lct-2026` (`b1g8c7gaanu3tnh3475r`) в облаке
`ai-sprints-cloud`; сервисный аккаунт `fsp-ai` с ролями
`ai.languageModels.user`, `ai.speechkit-stt.user`, `ai.speechkit-tts.user` и `search-api.webSearch.user` (веб-поиск агента, Search API v2) на каталог; API-ключ
`ajevat07l0fnmq9ts6oa` с областями `yc.ai.languageModels.execute`, `yc.ai.speechkitTts.execute` и
`yc.ai.speechkitStt.execute`. Секрет — только в `platform/.env`. Тот же ключ
включает голос через SpeechKit (`STT_PROVIDER=auto`) и озвучку аватара
(`TTS_PROVIDER=auto`; ключу нужна область `yc.ai.speechkitTts.execute`, роль
`ai.speechkit-tts.user` — в ключе лейна проверено ответом 200).
