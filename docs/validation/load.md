# Нагрузочный прогон (R-N-09)

Закрывает измеримость R-N-09 («десятки одновременных пользователей; подборка, профиль, поиск — приемлемое время»). Числового порога ТЗ не даёт.

- Дата и время (МСК): _заполняется после прогона_
- Версия стенда (git SHA): _заполняется после прогона_
- Скрипт: [`platform/loadtest/run.mjs`](../../platform/loadtest/run.mjs), Node 20+, без зависимостей
- Стенд: `fsp-stand`, `PRC50.2-4096` (2 vCPU с долей 50 %, 4 ГБ), Postgres, app и Caddy на одном хосте ([`deploy.md`](../deploy.md))
- Генератор нагрузки: ноутбук разработчика, по сети до стенда (RTT: _замерить_). Цифры включают сетевую задержку и ограничены одной машиной-генератором.
- Данные: демо-сид стенда (_N кандидатов, M вакансий — заполнить_). LLM: в сценарий не входит.

## Сценарий

Только чтение. Виртуальный пользователь (VU) один раз входит демо-работодателем `demo-employer` (`POST /api/demo/login`), затем по кругу, с паузой 1–4 с между запросами:

1. `GET /api/health`
2. `GET /api/employer/search` (7 вариантов фильтров: направление, грейд, стек, ФСП, категория)
3. `GET /api/employer/vacancies/demo-vac-be-m-1/matches?limit=20` (подборка по демо-потребности)

Ступени: прогрев 5 VU × 1 мин (в результаты не входит), затем 10 → 25 → 50 VU по 2 мин. Остановка, если доля ошибок на ступени выше 5 %.
VU здесь не равен реальному пользователю: пауза 1–4 с имитирует чтение экрана.

## Что не измеряли

- Ходы с LLM (консультант, оценка, голос): это внешний провайдер, не наша мощность.
- Запись: регистрация, прохождение теста, приглашения. Сценарий ничего не пишет, кроме согласий демо-работодателя при самом первом входе (идемпотентно).
- Stress до слома и нагрузка выше 50 VU.
- Запуск проектов в `runner`.
- Нагрузка с нескольких генераторов; влияние CDN и сети жюри.

## Воспроизвести

```bash
LOAD_SITE_COOKIE='<значение куки site_access>' BASE_URL=https://fsp-stars.ru \
  node platform/loadtest/run.mjs load-result.json
```

Необязательные переменные: `STAGES` (`10:120,25:120,50:120`, формат VU:секунды), `WARMUP` (`5:60`, пустая строка отключает), `THINK_MIN`/`THINK_MAX` (мс), `ABORT_RATE` (`0.05`), `EMPLOYER_ID`, `VACANCY_ID`. Код выхода 2 — прогон прерван по ошибкам.
