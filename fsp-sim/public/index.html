Откуда платформа берёт спортивные достижения

«ФСП Карьера» подтверждает достижения кандидата по реестру Федерации спортивного программирования: участник входит через ФСП ID, и платформа читает его записи из реестра. Настоящего API реестра участникам хакатона не дают, поэтому команда собрала его модель. На этой странице её можно потрогать: посмотреть ответы, изменить данные и убедиться, что платформа читает их отсюда, а не показывает заготовленный пример.

Это не сервис Федерации спортивного программирования. Контракт API — предложение команды, все люди и результаты вымышлены (синтетический набор), совпадения имён случайны. Каждый ответ помечен meta.simulator: true и заголовком X-FSP-Simulator: true.
  1. Нажмите кнопку — увидите настоящий запрос к API и ответ.
  2. Измените реестр — заведите участника, внесите ему достижение.
  3. Войдите этим участником на платформе — достижение появится в профиле.

1 Нажмите — и увидите ответ API

Каждая кнопка выполняет настоящие запросы из вашего браузера: сначала получает токен в ФСП ID, затем обращается к реестру. Ниже появятся все шаги — адрес, код ответа и JSON.

Запросы идут от имени участника … . Другого можно выбрать в разделе 2.

2 Измените реестр своими руками

Заведите участника, поправьте ему имя или регион, внесите достижение или разряд, удалите запись. Правка сразу попадает в реестр и в ФСП ID: кнопки из раздела 1 покажут её в ответах API, а созданным участником можно войти на платформе.

В настоящем реестре так нельзя: записи вносит федерация по протоколам соревнований. Здесь правка открыта всем, без входа — чтобы проверку можно было сделать за минуту. Записи, внесённые вручную, помечены.

Загрузка…

3 Проверьте на платформе

Платформа читает реестр в момент входа через ФСП ID. Поэтому после правки в разделе 2 войдите на платформе этим участником — и увидите свои изменения.

  1. Откройте платформу: fsp2.ru → «Войти» → «ФСП ID».
  2. На странице входа ФСП ID введите логин … и пароль … (пароль у всех участников симулятора общий).
  3. В «Настройках» платформы, в блоке «ФСП ID», будут записи этого участника — те же, что в ответе /me/achievements.
  4. Изменили реестр ещё раз — войдите через ФСП ID заново: платформа сохраняет снимок записей на момент входа.

Модель доступа

    
    
      
  • Открыто: справочники, соревнования, протоколы (фамилия с инициалами и регион, как в публикуемых протоколах), проверка записи по идентификатору.
    • 
      
  • Спортсмен (токен пользователя с fsp_id): свой профиль, достижения, разряды, согласия партнёрам.
    • 
      
  • Партнёр (client_credentials, роль partner): только спортсмены, давшие согласие именно этому клиенту, по областям profile, achievements, ranks. Без согласия — 403 consent_required.
    • 
      
  • Песочница (/api/v1/sandbox/*, без токена): ручные правки этой страницы. В настоящем реестре таких маршрутов нет.
    • 
      
  • Реестр не хранит личную роль в команде, ссылку на проект и стек: это сообщает сам кандидат, и платформа помечает это как его слова.
