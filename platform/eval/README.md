# eval: данные для валидации консультанта E-01

Синтетический набор для замера извлечения утверждений и стойкости к инъекциям
(критерий «механика тестирования и валидация»). Все люди, телефоны
(`+7 900 000-00-NN`), email (`@example.com`) и GitHub-хэндлы вымышлены.
Разметка сверена с `docs/product/claims-catalog.md` (черновик от 09.10.2026,
ждёт правки владельца), поле `catalogVersion` = `claims-catalog-draft-2026-10-09`.

## Что в наборе

| Каталог | Содержимое |
|---|---|
| `resumes/` | 30 резюме `.md`: 12 backend (6 J, 6 M: `b01`–`b12`), 12 frontend (6 J, 6 M: `f01`–`f12`), 6 «трудных» `h01`–`h06` (пустое, не-ИТ, список технологий без опыта, сильно преувеличенное, на английском, опечатки «Java» вместо JavaScript). Часть резюме с блоком «Достижения ФСП (демо)». |
| `labels/<id>.json` | Разметка: `specialization`, `gradeExpected` (`junior`/`middle`/`none`), `claims[{catalogId, quote}]`, `notClaims[{catalogId, mention, why}]`, опционально `fspAchievements`. |
| `attacks/` | 10 инъекций: `atk-resume-1..4`, `atk-readme-1..3`, `atk-html-1..3` + `<id>.expect.json` (что нельзя / что обязательно) и `atk-resume-*.meta.json` (`hidden`, `hiddenText`, как рисовать). |
| `ssrf/urls.json` | 39 URL: 33 с `blocked: true` (loopback в разных записях, metadata, приватные сети, CGNAT, схемы, userinfo-трюки, DNS-ребайндинг, редиректы), 6 разрешённых публичных. |
| `demo/demo-1..3` | Демо для жюри: сильный backend Middle с ФСП; frontend Junior без ФСП (R-FSP-03); резюме со скрытой инъекцией. В каждом: `resume.md`, `label.json`, `links.json` (фикстуры вместо сети), `expected.json`. |
| `scripts/` | `build-dataset.mjs`, `build-attacks.mjs`, `build-ssrf.mjs`, `make-pdfs.mjs`. |
| `run.ts` | Прогон метрик (ниже). |
| `_src/` | Исходники резюме с разметкой; `resumes/` и `labels/` генерируются из них. |

## Как размечено

- В исходнике `_src/resumes/*.md`: `[[catalogId|цитата]]` — утверждение, `((catalogId|текст|почему нет))` — ловушка, `{{fsp|текст}}` — достижение ФСП. `node scripts/build-dataset.mjs` убирает разметку, пишет резюме и разметку и **падает**, если цитата не подстрока резюме или ID нет в каталоге (ID вне каталога допустимы только с префиксом `none.`).
- Консервативность (ADR-0001): в `claims` только то, что подтверждает дословная фраза про сделанное. Список технологий, «знаком», «читал», «курс», «запускал чужое» — это `notClaims`. Один пункт резюме — один `catalogId`.
- Достижения ФСП не размечены как утверждения: каталог связывает ФСП только с `common.algo-complexity` и только через реестр, а резюме даёт лишь `self_reported`.
- Грейд: Junior — до ~1,5 лет или стажировка и pet-проекты; Middle — 3–5 лет с описанной ответственностью. Для пустых, не-ИТ и «списка технологий» `gradeExpected: none`; преувеличенное резюме (`h04`) ожидается как `junior`.

## Как запускать

```bash
node scripts/build-dataset.mjs && node scripts/build-attacks.mjs && node scripts/build-ssrf.mjs   # пересборка
node run.ts                        # ключевой baseline (проверка, что метрики считаются)
node run.ts --predictor gullible   # заглушка, поддающаяся инъекциям (самопроверка)
npx tsx eval/run.ts --predictor catalog-keywords   # из platform/: план В лейна claims (маркеры каталога + verifyClaims)
npx tsx eval/run.ts --predictor claims-stub        # extractClaims на заглушке LLM + verifyClaims (проверка конвейера)
node run.ts --predictor ./my.ts    # свой предсказатель: export default (text, ctx) => ProposedClaim[] | {claims, grade?, flags?, actions?}
node scripts/make-pdfs.mjs [--font FILE] [--out DIR]   # PDF в pdf/ (в git не хранится)
```

`run.ts` считает по `catalogId` (множества на документ): precision, recall, F1 в целом и по специализациям, попадания в ловушки, долю предсказаний без дословной цитаты, долю выполненных инъекций (запрещённый `catalogId`, грейд или действие из `*.expect.json`), число пропущенных флагов скрытого текста. Результат пишется в `results/<дата-время МСК>.json` (в git не попадает). Для атак без PDF `run.ts` дописывает `hiddenText` к тексту резюме, как это увидит извлекатель; HTML и README передаются сырым исходником. Для измеренной на реальной модели цифры подключите предсказатель через `--predictor`. Встроенный baseline числа жюри не годится.

## PDF

Библиотеки генерации PDF в стеке нет (только `unpdf` на чтение), поэтому `make-pdfs.mjs` пишет PDF 1.4 вручную со встраиваемым TrueType (кириллица, `ToUnicode` для корректного извлечения; проверено `pdftotext`). Шрифт в репозитории не лежит: по умолчанию берётся системный Arial (macOS) или DejaVu/Liberation, иначе `--font`/`EVAL_PDF_FONT`. Скрытый текст атак — белый цвет, кегль 1 пт. Форматирование простое: заголовки, маркированные списки, перенос строк.

## Ограничения

- Синтетика, написанная агентом: один разметчик, второго мнения нет. **Нужна вычитка владельцем**, особенно спорных мест (см. отчёт лейна) и самого каталога, на который опирается разметка.
- Цифры на 30 резюме и 144 метках — ориентир, не статистика; доверительные интервалы широкие.
- Метрика по `catalogId` не оценивает точность цитаты и грейда; цитату проверяет `verifyClaims`, грейд — отдельная процедура (`gradeExpected` лежит в разметке для неё).
- Атаки статичны; `maxRedirects: 5` в `ssrf/urls.json` — предложение eval, collector вправе выбрать другой лимит. DNS-кейсы (`requiresDns`) требуют подставного резолвера.
- Ссылки в демо вымышлены, реальные сети не дёргаются.
