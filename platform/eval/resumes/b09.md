~3 года в продакшене. Работаю в маркетплейсе доставки.

**Что делал за последние два года**
• Запустил обработку заказов через Kafka: 12 партиций, ключ по ид заказа, группы потребителей – гарантировал порядок событий одного заказа.
• Сделал дедупликацию событий в потребителе по идентификатору сообщения в таблице processed_events.
• Подключил распределённую трассировку OpenTelemetry и структурные логи с correlation id.
• Внедрил кэш-аside на Redis для карточек ресторанов, TTL и сброс при обновлении.
• Настроил GitHub Actions: тесты, сборка, выкладка на стейдж по тегу.
• Оптимизировал Dockerfile: multi-stage, образ уменьшился с 1.1 ГБ до 180 МБ.

**Стек:** Node.js, TypeScript, PostgreSQL, MongoDB (использовал в старом проекте, но схему проектировали до меня), Kafka, Redis.
