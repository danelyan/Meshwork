# Контракт: метрики классификации и разбиение выборки (ai.ml-engineering, junior)

Модуль `metrics.py` в корне репозитория. Окружение: Python 3.12, стандартная библиотека
(numpy тоже доступен, но не обязателен), без сети. Проверка – pytest. Входные последовательности – списки
или массивы numpy; метки классов – `int` или `str` (в одном вызове один тип), сравниваются по `==`.

```python
def confusion_matrix(y_true, y_pred, labels=None) -> list[list[int]]
def classification_report(y_true, y_pred, labels=None) -> dict
def roc_auc(y_true, y_score) -> float
def stratified_split(labels, test_size=0.25, seed=0) -> tuple[list[int], list[int]]
```

## Общие правила

- `y_true` и `y_pred` одной длины и непустые, иначе `ValueError`.
- `labels` – порядок классов. По умолчанию – отсортированное объединение значений `y_true` и `y_pred`.
  Пары, где метка (истинная или предсказанная) не входит в явно заданный `labels`, в подсчёт не попадают.

## `confusion_matrix`

Матрица `m[i][j]` – сколько объектов с истинным классом `labels[i]` предсказано как `labels[j]`.
Строки – истина, столбцы – предсказание. Элементы – обычные `int`.

## `classification_report`

Возвращает

```python
{
  "labels": [...],                                   # порядок как в confusion_matrix
  "per_class": {label: {"precision": p, "recall": r, "f1": f, "support": n}, ...},
  "macro": {"precision": p, "recall": r, "f1": f},   # простое среднее по классам из labels
  "micro": {"precision": p, "recall": r, "f1": f},   # TP, FP, FN суммируются по всем классам из labels
  "accuracy": a,                                     # доля верных среди учтённых пар
}
```

- `precision = TP / (TP + FP)`, `recall = TP / (TP + FN)`, `f1 = 2PR / (P + R)`; `support` – число объектов
  класса в `y_true` (среди учтённых пар).
- Если знаменатель равен нулю, значение метрики – `0.0` (не исключение и не `nan`).
- `macro["f1"]` – среднее `f1` по классам (а не F1 от усреднённых precision и recall).
- Значения метрик – `float`, `support` – `int`.

## `roc_auc`

`y_true` – только `0` и `1` (допустимы `bool`), `y_score` – числа (больше – «скорее класс 1»).
AUC – вероятность того, что случайный положительный объект получил оценку выше случайного отрицательного;
равные оценки считаются за половину. Результат – `float` от 0 до 1.
`ValueError`: длины не равны, пусто, метка не 0/1, в `y_true` нет одного из классов, в `y_score` есть `nan`.

## `stratified_split`

Делит индексы `0..len(labels)-1` на обучающую и тестовую части, сохраняя долю классов.

- Для каждого класса с `n` объектами в тест идёт `k = int(n * test_size + 0.5)` объектов, но не меньше 1
  и не больше `n - 1` (в обучении остаётся хотя бы один).
- Какие именно объекты класса попадут в тест, определяет `seed`: один и тот же `(labels, test_size, seed)` всегда
  даёт один и тот же результат (в том числе в другом процессе); другой `seed` обычно даёт другой выбор.
- Результат – два списка индексов `(train, test)`, каждый по возрастанию; вместе они покрывают все индексы ровно по одному разу.
- `ValueError`: `labels` пуст, `test_size` не в интервале `(0, 1)` (границы не допускаются), в каком-то классе меньше 2 объектов.
- Входной `labels` не изменяется. Глобальный генератор `random` не трогать.
