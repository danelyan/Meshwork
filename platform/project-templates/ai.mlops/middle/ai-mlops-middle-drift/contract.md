# Контракт: мониторинг дрейфа данных и предсказаний — PSI, KS, отчёт по окнам (Middle)

Python 3.12; можно `numpy`/`pandas` и стандартную библиотеку. Модуль `drift.py` в корне репозитория.
Эталонная выборка (то, на чём модель обучали) сравнивается с окнами боевого трафика. Предсказания модели
мониторятся так же, как признаки: это просто ещё один столбец с именем, например `"prediction"`.

Значения во входных последовательностях — `list`, `tuple` или `numpy.ndarray`. «Пропуск» — `None` или `nan`:
пропуски выбрасываются до всех расчётов. Входные данные функции **не изменяют**.

## Функции

```python
def psi(expected, actual, bins: int = 10, eps: float = 1e-4) -> float
def psi_categorical(expected, actual, eps: float = 1e-4) -> float
def ks_statistic(a, b) -> float
def severity(value: float, warn: float, alert: float) -> str
def drift_report(reference: dict, windows: list, thresholds: dict | None = None) -> dict
```

### `psi` — числовой признак
- Границы бинов: `bins` равных по ширине интервалов на `[min(expected), max(expected)]` (после удаления пропусков).
  Значение `x` попадает в бин `int((x - lo) / (hi - lo) * bins)`; значения `actual` вне диапазона эталона
  относятся к первому или последнему бину (клиппинг). Если все значения эталона равны (`hi == lo`) — бин один.
- Доли бинов `p = count / n` считаются отдельно для `expected` и `actual`; **доля меньше `eps` заменяется на `eps`**
  (пустой бин не даёт `ln(0)`; сумма после замены не нормируется).
- `PSI = Σ (a_i − e_i) · ln(a_i / e_i)` по всем бинам. Результат — `float`, всегда конечный и ≥ 0.
- `ValueError`: `bins < 1`, `eps <= 0`, после удаления пропусков пусто `expected` или `actual`.

### `psi_categorical` — категориальный признак
- Категории — значения как есть (`str`, `int`, `bool`, …), пропуск — не категория, он выбрасывается.
- Набор категорий — **объединение** эталона и окна. Доли считаются как у `psi`; новая категория (есть в `actual`,
  нет в `expected`) получает долю `eps` в эталоне, исчезнувшая — долю `eps` в окне. Порядок категорий на результат не влияет.
- `ValueError`: `eps <= 0` или пусто `expected`/`actual` после удаления пропусков.

### `ks_statistic`
Статистика двухвыборочного критерия Колмогорова–Смирнова `D = max |F_a(x) − F_b(x)|` по эмпирическим
функциям распределения `F(x) = доля значений ≤ x`, с корректной обработкой повторяющихся значений. Результат в `[0, 1]`.
p-value не нужен. `ValueError`, если после удаления пропусков одна из выборок пуста.

### `severity(value, warn, alert)`
`"alert"`, если `value >= alert`; иначе `"warn"`, если `value >= warn`; иначе `"ok"`. `ValueError`, если `warn > alert`.

### `drift_report`

```python
reference = {"age": [...], "country": [...], "prediction": [...]}
windows = [{"name": "2026-10-01", "data": {"age": [...], "country": [...], "prediction": [...]}}, ...]
```

Тип признака определяется **по эталону**: числовой, если все его непропущенные значения — `int`/`float` (не `bool`),
иначе категориальный. Пороги по умолчанию (`thresholds` может переопределить любые ключи, лишний ключ — `ValueError`):

| ключ | по умолчанию |
|---|---|
| `psi_warn`, `psi_alert` | 0.1, 0.25 |
| `ks_warn`, `ks_alert` | 0.1, 0.2 |
| `bins` | 10 |

Результат:

```python
{
  "windows": [
    {"window": "2026-10-01", "status": "ok" | "warn" | "alert" | "no_data",
     "features": {"age": {"type": "numeric", "psi": 0.03, "ks": 0.05, "status": "ok"},
                  "country": {"type": "categorical", "psi": 0.4, "ks": None, "status": "alert"},
                  "prediction": {"type": "numeric", "psi": None, "ks": None, "status": "no_data"}}}
  ],
  "summary": {"alert_windows": ["2026-10-03"], "first_alert": "2026-10-03" | None}
}
```
- Окна в результате в том же порядке, что и во входе; признаки — в порядке `reference`. Значения `psi`/`ks` не округляются.
- Статус числового признака — худший из `severity(psi, psi_warn, psi_alert)` и `severity(ks, ks_warn, ks_alert)`
  (порядок `ok < warn < alert`); категориального — только по PSI (`ks` = `None`).
- Если признака нет в окне или в нём не осталось значений после удаления пропусков — `psi`/`ks` = `None`,
  `status` = `"no_data"`. Такой признак не влияет на статус окна.
- Статус окна — худший статус его признаков; если у всех `no_data` (или признаков нет) — `"no_data"`.
- `summary.alert_windows` — имена окон со статусом `alert` в порядке входа; `first_alert` — первое из них или `None`.
- Признаки окна, которых нет в `reference`, игнорируются.
- `ValueError`: признак в `reference` без непропущенных значений; окно без `name` или `data`; неизвестный ключ порогов.
