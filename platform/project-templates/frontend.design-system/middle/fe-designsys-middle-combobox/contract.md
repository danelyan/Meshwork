# Контракт: Combobox и токены темы (frontend.design-system, middle)

React 19, TypeScript, без сторонних библиотек. Проверка — Testing Library в jsdom: роли, доступные имена, атрибуты ARIA
и клавиатурные события (`fireEvent.keyDown` на поле); CSS не проверяется. Два модуля: `src/Combobox.tsx` и `src/theme.tsx`.

## `src/Combobox.tsx`

```ts
export interface Option { value: string; label: string; disabled?: boolean }
export interface ComboboxProps {
  label: string;
  options: Option[];
  value?: string | null;          // задан (в т. ч. null) — контролируемый режим
  defaultValue?: string | null;   // начальное значение неконтролируемого режима
  onChange?: (value: string | null) => void;
  name?: string;
  disabled?: boolean;
}
export function Combobox(props: ComboboxProps): JSX.Element;
```

### Разметка
- Поле — `<input role="combobox">`, доступное имя — `label` (через `<label for>`), `aria-autocomplete="list"`,
  `autoComplete="off"`. Поле `disabled`, если `disabled`.
- Список закрыт при монтировании. Открытый список — элемент `role="listbox"` с уникальным `id`; он показывается, только
  если есть хотя бы один подходящий вариант. Пункты — `role="option"` с текстом `label`, у каждого уникальный `id`.
- `aria-expanded="true"`, только пока показан listbox; иначе `"false"`. `aria-controls` = id listbox, только пока он показан.
- Пока открыто и есть активный пункт, у поля `aria-activedescendant` = id активного пункта; иначе атрибута нет.
  Фокус остаётся в поле.
- У пункта `aria-selected="true"`, если он соответствует текущему значению, иначе `"false"`.
  У недоступного (`disabled: true`) пункта `aria-disabled="true"`.
- Если ничего не подошло — вместо listbox элемент `role="status"` с текстом **«Ничего не найдено»** (список при этом закрыт).
- `name` задан — рядом с полем скрытый `<input type="hidden" name="<name>">` со значением (пустая строка, если значения нет).

### Значение и текст в поле
- Текст поля, пока пользователь не печатал, — `label` выбранного варианта (или пусто). Значение, которого нет среди
  `options`, считается отсутствующим.
- Ввод текста открывает список и фильтрует варианты: `label` содержит введённую строку, регистр не важен, порядок исходный.
  Без ввода (открытие кликом или `ArrowDown`) показываются все варианты.
- Выбор варианта (клик по пункту или `Enter` на активном): список закрывается, в поле — его `label`, вызывается
  `onChange(value)`, **если значение отличается от текущего**. Недоступный вариант выбрать нельзя.
- **Контролируемый режим:** внутреннего состояния значения нет — показывается `value` из пропса; при выборе только
  вызывается `onChange`, пока родитель не передал новое значение, поле показывает прежнее. Смена `value` снаружи
  обновляет текст поля, пока пользователь не печатает.
- **Неконтролируемый режим** (`value` не передан): значение хранит компонент, начальное — `defaultValue` (по умолчанию `null`).
- Закрытие без выбора (`Escape`, уход фокуса с поля) возвращает в поле `label` выбранного варианта; введённый текст отбрасывается.

### Клавиатура (на поле)
- `ArrowDown` при закрытом списке: открыть; активным становится выбранный вариант, а если его нет — первый доступный.
  При открытом — следующий доступный пункт по кругу. `ArrowUp` — предыдущий по кругу (при закрытом — открывает
  и активирует последний доступный, если выбранного нет).
- Недоступные пункты при навигации пропускаются. `Home` / `End` при открытом списке — первый / последний доступный.
- Ввод текста сбрасывает активный пункт; активный пункт появляется после `ArrowDown`.
- `Enter` при открытом списке и активном пункте — выбрать его; в остальных случаях ничего не делает (форма не отправляется,
  пока список открыт: событие гасится `preventDefault`).
- `Escape` при открытом списке закрывает его (см. выше); при закрытом ничего не делает.
- Клик по полю открывает список (если поле не `disabled`); клик по пункту выбирает его.

## `src/theme.tsx`

Именованные токены. Значения по умолчанию:

| Токен | `light` | `dark` |
|---|---|---|
| `color.bg` | `#ffffff` | `#0b1220` |
| `color.text` | `#111827` | `#e5e7eb` |
| `color.primary` | `#2563eb` | `#60a5fa` |
| `space.2` | `8px` | `8px` |
| `radius.md` | `6px` | `6px` |

```ts
export type TokenName = 'color.bg' | 'color.text' | 'color.primary' | 'space.2' | 'radius.md';
export type ThemeName = 'light' | 'dark';
export function cssVarName(token: TokenName): string;      // 'color.bg' → '--ds-color-bg', 'space.2' → '--ds-space-2'
export function ThemeProvider(props: {
  theme?: ThemeName;                            // по умолчанию — тема родительского провайдера, на верхнем уровне 'light'
  overrides?: Partial<Record<TokenName, string>>;
  children?: React.ReactNode;
}): JSX.Element;
export function useToken(token: TokenName): string;        // значение токена в ближайшем провайдере
```

- `ThemeProvider` рендерит корневой `<div data-theme="<тема>">`, у которого в `style` заданы CSS-переменные **всех** токенов
  (`--ds-…` = значение) для выбранной темы с учётом `overrides`.
- Переопределения вложенных провайдеров складываются: значение берётся из `overrides` ближайшего провайдера,
  затем из `overrides` внешних, затем из таблицы темы. Тема вложенного провайдера без `theme` наследуется от родителя.
- `useToken` возвращает то же значение, что записано в переменную (с учётом темы и переопределений) и обновляется при смене
  `theme` и `overrides`. Вне провайдера возвращает значение светлой темы. Неизвестное имя токена — `Error` с текстом
  `Unknown token: <имя>`.
- Фиксированных идентификаторов, общих для нескольких провайдеров на странице, быть не должно.

Видимые тесты — `tests/visible/` (`npx vitest run tests/visible`).
