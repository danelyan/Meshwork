# Контракт: каталог товаров (frontend.ui-app, junior)

Модуль `src/ProductCatalog.tsx` экспортирует компонент `ProductCatalog({ products })`; тип `Product` —
в `src/types.ts` (файл платформы, не менять). Окружение проверки: Node.js 20, jsdom, React 19,
Testing Library; без сети, свои зависимости не устанавливаются, CSS не проверяется.

```ts
interface Product { id: string; name: string; category: string; priceRub: number; inStock: boolean }
```

## Что видит пользователь (проверяется по ролям и подписям, как у скринридера)

- Поле поиска с подписью **«Поиск»**: фильтрует по названию без учёта регистра и пробелов по краям.
- Выпадающий список с подписью **«Категория»**: первый вариант **«Все»**, затем уникальные категории
  по алфавиту (`localeCompare` с `ru`). Фильтры работают вместе.
- Текст **«Найдено: N»** — число товаров после фильтров.
- Список с подписью **«Товары»** (`role="list"`, `aria-label`), по пункту на товар в исходном порядке:
  название и цена в формате `1 990 ₽` (`Intl.NumberFormat('ru-RU')` + ` ₽`).
- Кнопка **«В корзину»** у каждого товара; у товара не в наличии — выключенная кнопка
  **«Нет в наличии»**. Каждое нажатие добавляет одну штуку.
- Область **«Корзина»** (`role="region"`, `aria-label="Корзина"`): **«Товаров: N»** (штук) и
  **«Сумма: X ₽»** в том же формате. Корзина не сбрасывается при смене фильтров.
- Ничего не нашлось — вместо списка текст **«Ничего не найдено»** и кнопка **«Сбросить фильтры»**,
  которая очищает поиск и возвращает «Все».

Видимые тесты — `tests/visible/` (`npx vitest run tests/visible`).
