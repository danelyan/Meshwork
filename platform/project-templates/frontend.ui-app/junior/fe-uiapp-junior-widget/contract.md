# Контракт: виджет «Список с фильтром» (frontend, junior)

Модуль `src/FilterList.jsx` экспортирует по умолчанию React-компонент `FilterList`.

Окружение проверки: Node.js 20, React 19, jsdom, Testing Library; зависимости не устанавливаются,
доступны только `react` и `react-dom`. JSX — в файлах `.jsx`; в начале файла `import React from 'react'`.

Пропсы: `items: string[]`, `placeholder?: string` (по умолчанию `"Поиск"`).

Поведение:

1. Поле ввода с ролью `searchbox` и доступным именем `Фильтр`; `placeholder` из пропсов.
2. Список (`role="list"`) показывает элементы `items`, в которых есть введённая строка без учёта
   регистра и пробелов по краям запроса; порядок исходный. Пустой запрос — все элементы.
3. Под полем — счётчик `Найдено: N` (элемент с `role="status"`).
4. Если совпадений нет — вместо списка текст `Ничего не найдено`.
5. Кнопка `Очистить` сбрасывает запрос и возвращает фокус в поле; при пустом запросе кнопка
   неактивна (`disabled`).

Видимые тесты — `tests/visible/` (`npx vitest run tests/visible --environment jsdom`). Платформа
проверяет решение своим набором тестов по этому контракту.
