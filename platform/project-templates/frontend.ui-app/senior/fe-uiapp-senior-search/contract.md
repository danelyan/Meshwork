# Контракт: поиск с подсказками — гонки запросов, кэш, доступность (Senior)

React 19, TypeScript, без сторонних библиотек состояния. Проверка — Testing Library в jsdom.

## `src/SearchBox.tsx`

```ts
export interface Item { id: string; title: string }
export interface SearchBoxProps {
  search: (query: string, signal: AbortSignal) => Promise<Item[]>;
  onSelect: (item: Item) => void;
  debounceMs?: number; // по умолчанию 250
  label?: string;      // по умолчанию «Поиск»
}
export function SearchBox(props: SearchBoxProps): JSX.Element;
```

### Запросы
- Запрос — значение поля без пробелов по краям. Пустой запрос: `search` не вызывается, список скрыт,
  запрос в полёте отменяется (`signal.aborted === true`).
- Дребезг: `search` вызывается, только когда ввод не менялся `debounceMs`; быстрый ввод «r», «re», «rea» —
  один вызов с «rea».
- Новый запрос отменяет предыдущий через `AbortSignal`. Ответ устаревшего запроса **никогда** не
  показывается, даже если `search` проигнорировал отмену и всё равно ответил (в том числе позже нового).
- Пока ответа нет — элемент `role="status"` с текстом «Загрузка…».
- Пустой ответ — `role="status"` с текстом «Ничего не найдено».
- Ошибка (кроме отмены) — `role="alert"` с текстом «Не удалось загрузить» и кнопка «Повторить»: она
  сразу повторяет тот же запрос.
- Кэш: успешный ответ запоминается по строке запроса; повтор того же запроса показывает результат без
  вызова `search` и без «Загрузка…». Хранятся последние 20 запросов (LRU: самый давний вытесняется).

### Список и клавиатура (WAI-ARIA combobox)
- Поле — `role="combobox"` с доступным именем `label`, `aria-autocomplete="list"`, `aria-controls` = id списка,
  `aria-expanded="true"`, когда показан непустой список, иначе `"false"`.
- Результаты — `role="listbox"`, пункты — `role="option"` с текстом `title`, у каждого уникальный `id`.
- `ArrowDown` / `ArrowUp` двигают активный пункт по кругу (первое нажатие `ArrowDown` — первый пункт);
  у поля `aria-activedescendant` = id активного пункта, у активного пункта `aria-selected="true"`.
- `Enter` — `onSelect(активный пункт)`; клик по пункту — `onSelect(пункт)`. `Escape` — закрыть список
  (`aria-expanded="false"`), текст в поле остаётся.
