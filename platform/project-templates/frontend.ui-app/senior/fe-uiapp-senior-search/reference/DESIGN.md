# Поиск с подсказками: проектные решения

## Решения
Каждый запрос получает номер; показывается только ответ последнего номера, а изменение ввода сразу
делает прежний запрос устаревшим и отменяет его через AbortController. Отмена экономит сеть, номер
защищает от API, которые отмену игнорируют. Дребезг ограничивает число запросов при быстром вводе.

## Компромиссы
Кэш по точной строке запроса без срока жизни: повторный ввод мгновенный, но данные могут устареть —
для каталога это приемлемо, для остатков на складе нет. Размер 20 — память против попаданий; LRU
держит недавние запросы. Пока идёт пауза дребезга, на экране остаётся прошлый список.

## Границы применимости
Для нескольких таких компонентов, фоновой ревалидации и общего кэша между экранами лучше взять
TanStack Query: дедупликация запросов и инвалидация из коробки. На сотнях пунктов нужна виртуализация
списка, а на большом каталоге — серверный поиск с префиксным индексом вместо фильтрации на клиенте.
