# Контракт: подсказки без лишних запросов (Junior)

React 19, TypeScript, без сторонних библиотек. Проверка — vitest с фейковыми таймерами и Testing Library в jsdom.
Все задержки отсчитываются только таймерами (`setTimeout`/`clearTimeout`), не `Date.now()`.

## `src/timing.ts`

```ts
export interface Cancelable { cancel(): void }
export function debounce<A extends unknown[]>(fn: (...args: A) => void, ms: number): ((...args: A) => void) & Cancelable;
export function throttle<A extends unknown[]>(fn: (...args: A) => void, ms: number): ((...args: A) => void) & Cancelable;
```

- `debounce`: `fn` вызывается один раз, через `ms` после **последнего** вызова, с аргументами этого последнего вызова.
  Каждый новый вызов сдвигает срабатывание. `cancel()` отбрасывает ожидающий вызов.
- `throttle`: первый вызов выполняется сразу. Вызовы в течение `ms` после выполнения не выполняются, а запоминаются;
  в конце окна `fn` вызывается один раз с аргументами **последнего** запомненного вызова, и сразу после него начинается
  новое окно длиной `ms`. Если запомненных вызовов не было, окно просто закрывается, и следующий вызов снова выполняется
  сразу. `cancel()` сбрасывает окно и запомненный вызов.

## `src/SuggestInput.tsx`

```ts
export interface SuggestInputProps {
  debounceMs?: number; // по умолчанию 300
  minLength?: number;  // по умолчанию 2
}
export function SuggestInput(props: SuggestInputProps): JSX.Element;
```

Подсказки загружает глобальный `fetch`: `fetch('/api/suggest?q=' + encodeURIComponent(query), { signal })`.
Ответ используется только через `res.ok` и `await res.json()`; тело — `{ "items": string[] }`.

- Поле — `<input>` с доступным именем «Поиск» (`aria-label`).
- Запрос — значение поля без пробелов по краям. Запрос короче `minLength` символов не отправляется; при этом показанный
  список очищается, а запрос в полёте отменяется (`signal.aborted === true`).
- Запрос уходит, только когда ввод не менялся `debounceMs`. Быстрый ввод «re», «rea», «reac» — один вызов `fetch`
  с `q=reac`. Пока длится пауза, `fetch` не вызывается.
- Запрос с тем же текстом, что уже загружен или загружается, повторно не отправляется (например, добавили пробел в конец).
- Новый запрос отменяет предыдущий в полёте через `AbortSignal`. Ответ устаревшего запроса не показывается никогда,
  даже если `fetch` проигнорировал отмену и всё равно ответил (в том числе позже нового).
- Пока ответа нет — `role="status"` с текстом «Загрузка…». Пустой список — `role="status"` с текстом «Ничего не найдено».
- Результаты — `<ul aria-label="Подсказки">`, каждая подсказка — `<li>` с текстом.
- Ответ с `res.ok === false` или ошибка сети (кроме отмены) — `role="alert"` с текстом «Не удалось загрузить».
  Отмена (`AbortError`) ошибкой не считается. Следующий успешный запрос убирает сообщение.
- При размонтировании: ожидающая пауза отменяется (`fetch` после этого не вызывается), запрос в полёте отменяется,
  состояние после размонтирования не обновляется.
