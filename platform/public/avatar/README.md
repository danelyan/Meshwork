# Голова компаньона — `head.glb`

Модель головы предоставил владелец проекта (сгенерирована в Tripo, 09.10.2026). Здесь лежит
облегчённая копия для web: только геометрия, без текстур и материала.

Подготовка из исходного файла (16 МБ, 52 тыс. вершин, три текстуры) — `@gltf-transform` 4 +
`meshoptimizer`:

1. материал и текстуры удалены, атрибуты TANGENT и TEXCOORD_0 сняты (сетка и металл рисуются
   шейдером, см. `src/components/avatar/Head3D.tsx`);
2. `weld` → `dedup` → `simplify` (meshopt, ratio 0.35, error 0.0015) → 20 386 вершин, 34 тыс.
   треугольников;
3. голова повёрнута лицом в +Z (исходная поза — поворот на 29°) и отцентрирована по X/Z;
   высота 0…1 от основания шеи до макушки.

Антропометрия (щель губ ≈ 0,43, низ подбородка ≈ 0,27, ось ушей ≈ 0,55) снята по профилю модели
и задана в `HEAD_MODEL` там же.

## `head-mouth.glb` — та же голова с настоящим ртом (основная)

Риг рта — Карины (`scripts/rig-head-mouth.py` в Blender, результат — `public/models/head-mouth.glb`, 20 МБ):
разрезанная щель губ со стенками, полость рта, зубы, язык (атрибут `_MOUTH_PART`: 0 голова, 1 полость,
2 зубы, 3 язык) и морфы `JawOpen`, `LipRound`, `LipWide`. Web-копию собирает `scripts/build-head-mouth.mjs`
(как запустить — в шапке скрипта), и голову он строит заново по её формулам, а не берёт из рига:

- **почему.** В риге центр рта — `center = 0` в её осях, а средняя линия лица там на ≈ 2 см в стороне
  (плоскость x = 0 рига у губ — это x ≈ −0,02 в системе `head.glb`; оси ещё повёрнуты на 1,6°). Разрез,
  парабола щели и вес челюсти съехали на одну щёку: при JawOpen = 1 щель была 35 мм на x = −6 см и 14 мм
  на x = +6 см, рот открывался криво. Кромки щели были прижаты к параболе только по высоте — по глубине
  ступеньки до 5 мм, в три четверти край зубчатый;
- **как.** Tripo-голова (`public/models/head.glb`) поворачивается на −29,35° и сдвигается в систему `head.glb`,
  швы развёртки свариваются. Плоскость симметрии лица — x = 0 (подбор по зеркальному совпадению поверхности:
  отклонение у рта ≤ 3 мм, наклон ≤ 1°). Дальше формулы рига с центром на этой плоскости: разрез по
  `seam(x)`, кромки — гладкая кривая и по высоте, и по глубине (чётный полином по x), уголки рта общие для
  обеих губ, кожа за кромкой подтянута; дельта нижней кромки — тоже гладкая кривая; стенки губ 3,5 см внутрь (`_LIP_WALL` = 1, шейдер гасит их в тёмное);
  JawOpen сглажен по связности (ступенька веса за уголками); дельты всех морфов зеркально усреднены
  относительно x = 0. Полость, зубы и язык — из рига Карины, выровнены на ту же линию;
- квантование позиций/нормалей (KHR_mesh_quantization) + meshopt (EXT_meshopt_compression).

Итог: 49 936 вершин (без упрощения), 0,48 МБ. Асимметрия JawOpen (зеркальные пары у рта): было 8,9 мм
rms, стало 0,05 мм; щель при JawOpen = 1 на x = ±2/±4/±6 см — 42,2/41,0, 40,7/40,2, 32,6/31,9 мм (было 45,6/43,9, 44,0/29,3, 34,7/14,3).
Квантование кладёт масштаб и сдвиг в узел — Head3D при загрузке возвращает позиции в единицы модели
(`modelSpaceGeometry`). Вид открытого рта — проп `mouthLook` (`src/components/avatar/mouth-looks.ts`), центр
полости в шейдере — x = 0. Если файл не загрузился, Head3D берёт `head.glb` с процедурным ртом.

Варианты вида (металл, сетка, плетение, хром, голограмма, частицы, нейросетка) — `src/components/avatar/head-styles.ts`,
сравнение на `/design/avatar`; в чате компаньона — «плетение».

`head.glb` — 0,7 МБ (0,5 МБ gzip). Обе модели грузятся лениво только на страницах с аватаром и только при WebGL.
