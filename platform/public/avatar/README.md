# Голова компаньона — `head.glb`

Модель головы предоставил владелец проекта (сгенерирована в Tripo, 09.10.2026). Здесь лежит
облегчённая копия для web: только геометрия, без текстур и материала.

Подготовка из исходного файла (16 МБ, 52 тыс. вершин, три текстуры) — `@gltf-transform` 4 +
`meshoptimizer`:

1. материал и текстуры удалены, атрибуты TANGENT и TEXCOORD_0 сняты (сетка и металл рисуются
   шейдером, см. `src/components/avatar/Head3D.tsx`);
2. `weld` → `dedup` → `simplify` (meshopt, ratio 0.35, error 0.0015) → 20 386 вершин, 34 тыс.
   треугольников;
3. голова повёрнута лицом в +Z (исходная поза — поворот на 29°) и отцентрирована по X/Z;
   высота 0…1 от основания шеи до макушки.

Антропометрия (щель губ ≈ 0,43, низ подбородка ≈ 0,27, ось ушей ≈ 0,55) снята по профилю модели
и задана в `HEAD_MODEL` там же.

## `head-mouth.glb` — та же голова с настоящим ртом (основная)

Источник — `public/models/head-mouth.glb` (риг Карины, `scripts/rig-head-mouth.py` в Blender из той
же Tripo-модели, 20 МБ): разрезанная щель губ со стенками, полость рта, зубы, язык (атрибут
`_MOUTH_PART`: 0 голова, 1 полость, 2 зубы, 3 язык) и морфы `JawOpen`, `LipRound`, `LipWide`.
Облегчённая копия собирается скриптом `scripts/build-head-mouth.mjs` (как запустить — в шапке скрипта):

1. материал, текстуры и TEXCOORD_0 сняты; морфы (позиции и нормали) и `_MOUTH_PART` оставлены;
2. поворот на −29,35° вокруг Y и сдвиг по X/Z — в систему `head.glb` (подобраны по совпадению вершин,
   расхождение ≈ 0,2 мм);
3. дельта `JawOpen` сглажена по связности сетки: в риге вес челюсти скачком 0 → 0,55 на линии разреза,
   и за уголками рта кожа рвалась ступенькой (сетка шла зигзагом); щель губ разрезана, её сглаживание
   не трогает;
4. стенки губ (риг относит их к голове) помечены атрибутом `_LIP_WALL` — шейдер гасит их в тёмное (как именно
   выглядит открытый рот — проп `mouthLook`, варианты в `src/components/avatar/mouth-looks.ts`);
5. квантование позиций/нормалей (KHR_mesh_quantization) + meshopt (EXT_meshopt_compression).

Итог: 54 004 вершины (без упрощения), 0,5 МБ. Квантование кладёт масштаб и сдвиг в узел — Head3D
при загрузке возвращает позиции в единицы модели (`modelSpaceGeometry`). Если файл не загрузился,
Head3D берёт `head.glb` с процедурным ртом.

Варианты вида (металл, сетка, плетение, хром, голограмма, частицы, нейросетка) — `src/components/avatar/head-styles.ts`,
сравнение на `/design/avatar`; в чате компаньона — «плетение».

`head.glb` — 0,7 МБ (0,5 МБ gzip). Обе модели грузятся лениво только на страницах с аватаром и только при WebGL.
